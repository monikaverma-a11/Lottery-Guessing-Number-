# Number Guessing Lottery

## Introduction

Number Guessing Lottery is a simple web-based PHP project developed to demonstrate
the basic concepts of PHP programming, HTML forms, CSS styling, random number generation, 
and conditional logic.
The project allows a user to enter six numbers of their choice. When the user clicks the 
"Check Numbers" button, the system generates six different random numbers between 1 and 50. 
The entered numbers are then compared with the generated numbers, and the matching numbers are
displayed on the screen.

## Project Objective
The main objective of this project is to create a simple and interactive number matching game 
using PHP. It helps in understanding how user input is received through an HTML form and processed 
using PHP.

## Features

- User can enter six numbers.
- The system generates six different random numbers.
- User numbers are compared with generated numbers.
- Matching numbers are displayed.
- Total number of matches is calculated.
- Displays "No matches" when no number matches.
- Simple and easy-to-use interface.
- No database is required.

## Technologies Used

- PHP
- HTML
- CSS

## Working of the Project

First, the user enters six numbers in the provided input fields.
After clicking the "Check Numbers" button, the PHP program generates
six unique random numbers between 1 and 50.
The program then compares each number entered by the user with the generated numbers. 
If a number is found in both sets, it is added to the matching numbers list.

Finally, the application displays:
- Generated Numbers
- Your Numbers
- Matching Numbers
- Total Matches

## How to Run the Project

1. Install PHP on the system.
2. Open the project folder using a PHP-supported environment.
3. Start a PHP development server.
4. Open the project URL in a web browser.
5. Enter six numbers.
6. Click the "Check Numbers" button.
7. View the generated and matching numbers.

## Advantages

- Easy to understand and use.
- Demonstrates basic PHP concepts.
- Does not require a database.
- Provides instant results.
- Useful for beginners learning PHP.

## Future Scope

The project can be improved by adding a scoring system,
multiple game levels, a better user interface, a timer, and a 
history of previous results. A database can also be added in the future
to store player records and scores.

## Conclusion

Number Guessing Lottery is a simple PHP-based project that demonstrates 
how user input, random number generation, comparison, and result display 
can be implemented in a web application. The project provides a basic understanding 
of PHP and can be further enhanced with additional features.
